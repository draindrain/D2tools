# Fonts

Put a licensed copy of the Diablo II font here to use it across the site:

- `exocet.woff2` (preferred) or `exocet.otf`

The font is not included because it is commercial (Exocet by Emigre, licensed to
Blizzard). If no file is present, the site uses the font when the viewer has it
installed, and otherwise falls back to Cinzel from Google Fonts.
